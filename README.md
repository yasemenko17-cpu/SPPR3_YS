# Стартовий проєкт SP-P03

1. Відкрийте проєкт у GitHub Codespaces (Code → Codespaces → Create codespace) або локально в Linux: `python3 -m venv .venv`, `source .venv/bin/activate`, `pip install -r requirements.txt`.
2. Визначте свою задачу й набір за номером варіанта (розділ 5 інструкції) і відкрийте файл `variants/variant_NN.py` з номером задачі.
3. Реалізуйте функцію `solve` за карткою свого варіанта.
4. Запускайте відкриті тести лише для свого варіанта: `pytest -k v13` (де 13 — номер варіанта).
5. Змінюйте лише свій файл у `variants/` (і за бажанням `tests/test_my.py`).
